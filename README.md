# SQL PROJECT (BRAZILIAN E-COMMERCE PROJECT) )

SQL-based analysis of Brazilian E-commerce dataset to uncover customer behavior, sales trends, delivery performance, and seller insights.

This project focuses on analyzing a real-world Brazilian E-commerce dataset using SQL. The goal is to extract meaningful business insights related to customer behavior, order patterns, revenue trends, delivery performance, and seller efficiency.

The analysis includes data exploration, aggregation, and advanced SQL techniques such as joins, window functions, and common table expressions (CTEs). Various business questions are answered, such as identifying top customers, best-selling product categories, revenue distribution, delivery delays, and customer review patterns.

This project demonstrates practical SQL skills and the ability to work with real-world datasets to solve business problems and generate actionable insights.

This project is ideal for showcasing SQL proficiency for data analyst roles.
